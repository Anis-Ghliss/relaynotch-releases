# RelayNotch releases

RelayNotch is downloaded and updated from **[relaynotch.app](https://relaynotch.app)** now:

- Download: https://relaynotch.app/download
- Homebrew: `brew install --cask anis-ghliss/tap/relaynotch`

This repo only keeps the update feed that copies of RelayNotch 1.5.1 and older still check. It points them to relaynotch.app, and after one update they check relaynotch.app directly.
